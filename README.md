# EcoTracker - MVP Sprint de Gestão Ágil

> **Aplicativo de gestão sustentável gamificado para monitoramento de consumo de recursos**

![EcoTracker Logo](https://img.shields.io/badge/EcoTracker-Sustentabilidade-4CAF50?style=for-the-badge&logo=leaf)

## 📋 Sobre o Projeto

O **EcoTracker** é um aplicativo mobile desenvolvido como MVP para a disciplina de Gestão Ágil de Projetos e Produtos. A solução permite que famílias e pequenas empresas monitorem, analisem e reduzam seu consumo de água e energia através de gamificação inteligente e insights personalizados.

### 🎯 Proposta de Valor
*"Monitore e reduza seu consumo de recursos através de gamificação inteligente e insights personalizados"*

## 🏗️ Metodologia Utilizada

Este projeto foi desenvolvido seguindo as melhores práticas de gestão ágil:

- **Lean Inception** - Workshop de 5 dias para definição do MVP
- **Scrum** - Framework ágil para gestão do desenvolvimento
- **User Stories** - Histórias de usuário com critérios de aceitação detalhados
- **Design Thinking** - Foco na experiência do usuário e prototipação

## 🎯 Definition of Ready (DoR)

Um item está pronto para desenvolvimento quando:

- [ ] História escrita no formato "Como... quero... para..."
- [ ] Critérios de aceitação definidos e testáveis
- [ ] Story points estimados pela equipe
- [ ] Dependências técnicas identificadas
- [ ] Mockups/wireframes disponíveis
- [ ] Product Owner aprovou a história

## ✅ Definition of Done (DoD)

Um item está concluído quando:

- [ ] Código desenvolvido e revisado
- [ ] Testes unitários criados e passando
- [ ] Interface responsiva implementada
- [ ] Acessibilidade básica (WCAG AA)
- [ ] Performance < 3 segundos
- [ ] QA executou testes de aceitação
- [ ] Deploy em ambiente de homologação
